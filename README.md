# Радар Кэфа МСК (SurgeRadar) v1.9.2

Карта и мини-окошко спроса на такси по Москве и Подмосковью, вердикт по заказам Яндекс Про, горячие места.

## Как обновлять поверх старой версии

С версии 1.9.2 приложение подписывается постоянным ключом из папки `signing/`.
Поэтому каждая следующая сборка из GitHub ставится поверх установленной, без удаления,
и настройки, ключ расписаний и история сохраняются.

1. Загрузите новый ZIP в репозиторий (старый ZIP удалите) и запустите Actions → Run workflow.
2. Скачайте артефакт, распакуйте, откройте `app-debug.apk` и нажмите «Обновить».

Один раз, при переходе на 1.9.2 с более ранней версии, старую нужно удалить: раньше каждая сборка
получала случайную подпись, и Android не даёт поставить такую поверх. После удаления слетят настройки,
доступ к экрану и включённый виджет. Потом так больше не будет.

Важно: версия (versionCode) в `app/build.gradle` должна расти в каждом новом ZIP, иначе Android откажет.
Ключ лежит в репозитории: если репозиторий публичный, лучше сделать его приватным.

## Что есть
- Мини-окошко со всеми выбранными тарифами по вашему месту (GPS), вердикт по заказу с анимацией
- Горячие места по двойному тапу: аэропорты, вокзалы, концерты, больницы
- Диагностика чтения Яндекс Про: Настройки → Диагностика
